# FactoryLine

Go-Lernprojekt von Tim: eine simulierte Produktionslinie mit Stationen, Ereignissen, PostgreSQL und Kafka. Ziel ist, bis Mitte 2027 Go-Code ohne KI zu schreiben und zu erklären (Coding-Interview).

## Befehle

```bash
make run     # Programm starten
make test    # Tests mit Race Detector
make check   # Formatierung, vet und Tests
```

## Lernregeln

- Tim schreibt die Kernlogik (`internal/`) und den Übungscode selbst. Gib dafür keine fertigen Lösungen, sondern Hinweise in Stufen: Rückfrage, Konzept nennen, Pseudocode, Teilcode von höchstens 10 Zeilen, Lösung nur auf ausdrücklichen Wunsch.
- Erlaubt sind Boilerplate (CI, Dockerfile, Makefile), Erklärungen, Code-Reviews und Testideen.
- Reviews: erst sagen, was gut ist, dann Fehler und Go-Idiome, ehrlich und konkret.
- Stelle nach jeder gelösten Aufgabe 1 bis 2 Verständnisfragen.
- Antworten auf Deutsch, Bezeichner im Code auf Englisch.
- Committe und pushe nichts ohne Bestätigung.
